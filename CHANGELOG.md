# Changelog

## 0.1.0 — Unreleased

- Fourteen canonical engineering skills with discovery, decision rules, checklists and realistic examples.
- Manifest-driven TypeScript CLI for selection, installation, listing and removal.
- Generic, Cursor, Codex and Claude Code project-local presets.
- Ownership receipts, edit detection, overwrite protection, path/link checks and per-preset locking.
- Manifest/content validation and filesystem integration tests using Node's test runner.
- Contributor documentation and a Windows/Linux Node 22/24 CI workflow.
- `install` defaults to the generic preset; `remove` detects the preset and refuses to guess when ambiguous.
- `npm run cli` targets the directory npm was invoked from instead of the package root.
- Validator enforces the required `SKILL.md` headings in order.

No npm package or GitHub release has been published by this project setup.
